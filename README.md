# Linux Log Analyzer

## Description
A simple Bash script that displays useful Linux system information.

## Features
- Current User
- Date and Time
- Hostname
- Disk Usage
- Memory Usage
- System Uptime
- Failed Login Attempts

## Technologies Used
- Linux
- Bash
- Git
- GitHub

## How to Run

bash
chmod +x log_analyzer.sh
./log_analyzer.sh
